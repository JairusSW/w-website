01 / THE APPROACH

Less runtime overhead.
More room for your code.

Useful building blocks with low-level control when your work calls for it.

01

Skip the garbage collector.

W uses no garbage collector or conventional heap. It reuses temporary storage and constructs results directly in their destinations.

02

Reduce unnecessary work.

W is designed to eliminate intermediate objects, fuse operations, and specialize hot paths. Less time moving data that does not need to exist.

03

Keep control when it matters.

Explicit numeric types, pointers, fixed arrays, and typed memory operations are part of the design, alongside SIMD and atomics.

02 / THE SYNTAX

Familiar structure.
Clear intent.

The function adds the integers from zero up to, but not including, limit. For example, sum(10) returns 45.

pub fn
Declares an exported function.
mut
Allows a local value to change.
rt
Returns the result.
sum.w
pub fn sum(limit: i32): i32 {
  mut total: i32 = 0
  mut index: i32 = 0

  while index < limit {
    total += index
    index += 1
  }

  rt total
}
