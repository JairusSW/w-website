01 / DESIGN PRINCIPLES

Control the details.
Keep the big picture.

Practical building blocks.
A deliberately different foundation.

[↯]

Work, without the waste.

Eliminate intermediate objects. Fuse operations. Specialize hot paths. W is designed to spend less time on data that never needed to exist.

[◌]

Carry less memory.

Reuse temporary storage and construct results in their destinations. No garbage collector or conventional heap along for the ride.

[⌘]

Go low when it counts.

Pointers, fixed arrays, typed memory operations, SIMD, and atomics are part of W’s design. Reach for precision when you need it.

Clear syntax.
Real intent.

No ceremony to get in the way. A small function with explicit types and a result you can follow, line by line.

NATIVE TARGET / EXPERIMENTAL

sum.w
pub fn sum(limit: i32): i32 {
  mut total: i32 = 0
  mut index: i32 = 0

  while index < limit {
    total += index
    index += 1
  }

  rt total
}
