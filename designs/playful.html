A little less overhead.
A little more headspace.

↯

Make every
operation count.

W is designed to eliminate intermediate objects, fuse operations, and specialize hot paths. A lot can happen when there’s less in the way.

◌

Pack light.
Think bigger.

No garbage collector or conventional heap. W reuses temporary storage and constructs results where they belong. Travel with a little less baggage.

{ }

Find your feet.
Then go deeper.

Familiar functions and explicit types make a friendly starting point. Pointers, SIMD, and typed memory operations are there when your work needs them.

pub fn sum(limit: i32): i32 {
  mut total: i32 = 0
  mut index: i32 = 0

  while index < limit {
    total += index
    index += 1
  }

  rt total
}
