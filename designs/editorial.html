A DIFFERENT FOUNDATION

Less to carry.
More to create.

01

Make room for the work.

W is designed to eliminate intermediate objects, fuse operations, and specialize hot paths. Less data moving around. More work getting done.

02

Leave the heap behind.

Temporary storage is reused. Results are constructed in their destinations. W takes a different approach to memory, without a garbage collector.

03

Keep your bearings.

Explicit numeric types, familiar functions, and inference for ordinary code. A precise language that feels approachable from the first line.

THE SHAPE OF W

Easy to read.
Worth a closer look.

A function, a loop, a result. W keeps the familiar building blocks and rethinks what sits beneath them.

fn / mut / while / rt

sum.w
pub fn sum(limit: i32): i32 {
  mut total: i32 = 0
  mut index: i32 = 0

  while index < limit {
    total += index
    index += 1
  }

  rt total
}
